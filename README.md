Este repositorio contiene la **identidad visual oficial de Tasztex®**: manual de marca, sistema de logos y archivos listos para usar.

Sirve como _press kit_ y _brand guidelines_ para agencias, proveedores de diseño, periodistas, socios comerciales y cualquier persona que necesite producir piezas en nombre de la marca o representarla en sus propios materiales.

## Tipografía

- **Titulares:** [Montserrat](https://fonts.google.com/specimen/Montserrat) (700 Bold / 900 Black) — Google Font gratuita.
- **Cuerpo:** [Open Sans](https://fonts.google.com/specimen/Open+Sans) (400 Regular / 600 Semibold / 700 Bold) — Google Font gratuita.
- **Sustitutos seguros:** Arial Bold (titulares) y Calibri (cuerpo) cuando Montserrat/Open Sans no estén disponibles.

## Reglas rápidas de uso

✅ **Sí**
- Mantener un área de protección equivalente a la altura de la letra "T" alrededor del logo.
- Usar la versión correcta según el contexto (ver tabla arriba).
- Mantener contraste mínimo 4.5:1 entre texto y fondo (WCAG AA).

❌ **No**
- Deformar, estirar ni rotar el logo.
- Cambiar los colores del logo.
- Agregar sombras, gradientes, brillos o efectos.
- Reemplazar la tipografía del wordmark por otra.
- Combinar el sello circular con el lockup completo en la misma pieza.

> El detalle completo está en [`manual/Manual_de_Marca_Tasztex_v2.pdf`](manual/Manual_de_Marca_Tasztex_v2.pdf).

## Líneas de producto

Tasztex® opera con un sistema visual unificado que sirve a sus 5 líneas de producto. La diferenciación entre líneas se hace por **etiqueta**, no por cambio de paleta o tipografía.

- **AGRO** — protección y bienestar del ganado, cubiertas para tanques rurales, comederos.
- **TRANSPORTE** — coberturas para camiones y vehículos náuticos.
- **INDUSTRIA** — fundas y cobertores para maquinaria y estructuras.
- **TOLDOS y CORTINAS** — tensoestructuras y coberturas arquitectónicas automatizadas.
- **MINERÍA, PETRÓLEO y GAS** — geomembranas y geotextiles para obras civiles.
